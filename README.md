# روان‌سرا 🌿 — سایت کلینیک روان‌درمانی

سایت مدرن، تک‌زبانه (فارسی RTL) با موشن‌گرافی روز، برای روان‌شناسان و کلینیک‌های روان‌درمانی.
آماده انتشار روی **GitHub Pages** — بدون بیلد، بدون وابستگی، فقط HTML/CSS/JS خالص.

## ✨ امکانات

- **طراحی روز ۲۰۲۶:** تایپوگرافی متحرک (فونت متغیر وزیرمتن)، چیدمان ارگانیک، گلس‌مورفیسم، بلاب‌های متحرک، پارالاکس ماوس، نوار متحرک (marquee)، شمارنده آمار و انیمیشن‌های اسکرول
- **تمرین تنفس تعاملی** در هیرو (الگوی ۴-۲-۴ با راهنمای صوتی‌گونه بصری)
- **دو تست استاندارد خودسنجی** با نتیجه فوری:
  - GAD-7 (اضطراب)
  - PHQ-9 (خلق) — با پیام مراقبت برای امتیازهای بالا
- **بلاگ** با ۳ مقاله کامل آماده
- **فرم رزرو** با اعتبارسنجی + نمایش موفقیت
- **کاملاً واکنش‌گرا** + پشتیبانی از `prefers-reduced-motion` (دسترس‌پذیری)
- SEO پایه: متا، Open Graph، JSON-LD (Schema.org)

## 📮 اتصال فرم رزرو به ایمیل (Formspree)

فرم فعلی به‌صورت نمایشی فقط پیام موفقیت نشان می‌دهد. برای دریافت واقعی پیام‌ها:

1. در [formspree.io](https://formspree.io) ثبت‌نام کنید و یک فرم بسازید (پلن رایگان: ۵۰ پیام/ماه)
2. آدرس اکشن فرم را در `index.html` پیدا کنید (`id="bookingForm"`) و به شکل زیر تغییر دهید:
   ```html
   <form class="contact__form" id="bookingForm"
         action="https://formspree.io/f/XXXXXXXX" method="POST" data-reveal>
   ```
3. در `assets/js/main.js` بلاک «فرم رزرو» را پیدا کنید و `e.preventDefault();` را حذف کنید تا ارسال واقعی انجام شود.

## 🚀 انتشار روی GitHub Pages

1. در گیت‌هاب یک ریپازیتوری جدید بسازید (Public، مثلاً `ravansara`)
2. کل محتویات این پوشه را آپلود کنید (بدون خودِ پوشه):
   ```bash
   git init
   git add .
   git commit -m "روان‌سرا: نسخه اول"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO.git
   git push -u origin main
   ```
3. در ریپو: **Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save**
4. پس از یکی دو دقیقه، سایت روی `https://USERNAME.github.io/REPO/` فعال است

برای دامنه اختصاصی: فایل `CNAME` (محتویات: فقط دامنه) در ریشه بسازید و رکورد CNAME دامنه را به `USERNAME.github.io` متصل کنید.
